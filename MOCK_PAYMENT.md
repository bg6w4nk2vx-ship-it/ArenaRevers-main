# Локальная система оплаты (без Stripe API)

## Что изменилось

Система оплаты теперь работает **без реальных вызовов к Stripe API**. Все платежи обрабатываются локально и всегда возвращают успешный результат.

## Как это работает

1. **Mock Payment Service** (`mockPaymentService.js`) - локальный сервис, который:
   - Создает фиктивные ID для платежей
   - Всегда возвращает успешный результат
   - Не требует реальных API ключей
   - Работает полностью офлайн

2. **Автоматическая замена** - все вызовы Stripe API автоматически заменены на mock сервис

## Преимущества

✅ **Не требует Stripe API ключей** - работает без настройки  
✅ **Всегда успешная оплата** - идеально для тестирования  
✅ **Работает офлайн** - не нужен интернет для тестирования  
✅ **Быстрая обработка** - нет задержек на API вызовы  

## Использование

Просто используйте любые данные карты при оплате:
- **Номер карты:** любой (например, `1234 5678 9012 3456`)
- **Дата:** любая в будущем
- **CVC:** любой (например, `123`)
- **Имя:** любое

**Результат:** Оплата всегда будет успешной! ✅

## Возврат к реальному Stripe

Если нужно вернуться к реальному Stripe API:

1. В `paymentService.js` замените:
   ```javascript
   import { createPaymentSession as createMockPaymentSession } from './mockPaymentService.js';
   ```
   на:
   ```javascript
   import { createPaymentSession } from './stripeService.js';
   ```

2. И замените `createMockPaymentSession` на `createPaymentSession`

3. Установите переменную окружения:
   ```env
   USE_MOCK_PAYMENT=false
   ```

## Логи

При использовании mock сервиса в консоли будут выводиться сообщения:
- `💳 Mock payment: Payment method created successfully`
- `✅ Mock payment: Payment confirmed successfully`
- `📥 Mock webhook: Processing payment webhook`

Это помогает отслеживать процесс оплаты без реальных API вызовов.
