# Настройка Stripe для работы с данными карт

## Предупреждение

Если вы видите предупреждение:
```
Sending credit card numbers directly to the Stripe API is generally unsafe
```

Это означает, что приложение отправляет данные карты напрямую в Stripe API. Это работает, но Stripe рекомендует использовать более безопасные методы.

## Решения

### Вариант 1: Включить Raw Card Data API (для тестирования)

1. Перейдите в [Stripe Dashboard → Settings → API](https://dashboard.stripe.com/settings/api)
2. Найдите раздел "Raw card data APIs"
3. Включите опцию "Enable raw card data APIs"
4. Это позволит отправлять данные карт напрямую в тестовом режиме

**⚠️ ВНИМАНИЕ:** Это только для тестирования! В production используйте Stripe Elements.

### Вариант 2: Использовать Test Tokens (рекомендуется)

Вместо отправки реальных данных карты, используйте test tokens от Stripe:

**Для успешной оплаты:**
- Используйте test token: `tok_visa` или `tok_visa_debit`

**Для отклоненной карты:**
- Используйте test token: `tok_chargeDeclined`

**Как использовать:**
Вместо отправки `cardNumber`, `expiryMonth`, `cvv` - отправляйте только `paymentMethodToken`.

### Вариант 3: Использовать Stripe Elements (лучший для production)

Для production рекомендуется использовать [Stripe Elements](https://stripe.com/docs/stripe-js) на фронтенде, который:
- Безопасно собирает данные карты
- Создает Payment Method токены
- Соответствует PCI DSS требованиям

## Текущая реализация

Сейчас приложение использует прямой ввод данных карты. Это работает в тестовом режиме, но:

1. **Для тестирования:** Включите Raw Card Data API в Stripe Dashboard
2. **Для production:** Перейдите на Stripe Elements

## Тестовые карты Stripe

Если вы используете прямую отправку данных, используйте тестовые карты:

- **Успешная оплата:** `4242 4242 4242 4242`
- **Отклоненная карта:** `4000 0000 0000 0002`
- **Требует 3D Secure:** `4000 0025 0000 3155`

Любая дата в будущем, любой CVC (например, 123).

## Безопасность

⚠️ **ВАЖНО:** 
- Никогда не логируйте данные карт
- Не храните данные карт в базе данных
- Используйте HTTPS для всех запросов
- В production обязательно используйте Stripe Elements
