# ArenaReserve - Объяснение проекта для дизайна

## 📋 Обзор проекта

**ArenaReserve** (также известный как **ArenaBook**) — это полнофункциональная платформа для бронирования спортивных арен в Казахстане. Платформа позволяет пользователям находить, просматривать и бронировать спортивные арены с возможностью онлайн-оплаты.

### Основная концепция
- **Целевая аудитория**: Спортсмены, любители активного отдыха, спортивные команды
- **География**: Казахстан (в основном Алматы, но поддерживается расширение)
- **Язык интерфейса**: Казахский язык (Qazaq)
- **Основная ценность**: Быстрое и удобное бронирование спортивных арен с гарантией доступности

## 🎯 Основные функции и пользовательские сценарии

### 1. Поиск и просмотр арен

**Пользовательский сценарий:**
- Пользователь открывает главную страницу
- Видит поисковую строку и фильтры
- Может искать арены по типу спорта, местоположению, цене
- Просматривает карточки арен с изображениями, рейтингом, ценой
- Может открыть детальную информацию об арене

**Ключевые элементы:**
- Поисковая строка с автодополнением
- Фильтры: тип спорта, диапазон цен
- Сетка карточек арен (3 колонки на десктопе, 1-2 на мобильных)
- Модальное окно с деталями арены

### 2. Бронирование арены

**Пользовательский сценарий:**
1. Пользователь выбирает арену
2. Нажимает "Брондау" (Бронировать)
3. Если не авторизован → открывается модальное окно входа/регистрации
4. После авторизации открывается модальное окно бронирования
5. Выбирает дату, время и продолжительность
6. Система показывает доступность (календарь с занятыми/свободными слотами)
7. Подтверждает бронирование
8. Переходит к оплате

**Особенности:**
- Защита от двойного бронирования (PostgreSQL EXCLUDE constraint)
- Система временных резерваций (HOLD) на 5-10 минут при онлайн-оплате
- Автоматическая отмена expired holds через cron job
- Валидация доступности в реальном времени

### 3. Система оплаты

**Поддерживаемые провайдеры:**
- **Stripe** — онлайн-оплата картами
- **Kaspi Pay** — популярная платежная система в Казахстане
- **Cash** — наличная оплата на месте

**Типы оплаты:**
- **Full** — полная оплата
- **Deposit** — частичная оплата (задаток)

**Процесс оплаты:**
1. После создания бронирования создается платеж
2. Бронирование получает статус "hold" (временная резервация)
3. Пользователь вводит данные карты в модальном окне
4. При успешной оплате:
   - Бронирование переходит в статус "confirmed"
   - Генерируется чек (PDF)
   - Отправляется уведомление
5. При неудачной оплате:
   - Бронирование автоматически отменяется через 10 минут
   - Пользователь может повторить попытку

### 4. Управление бронированиями

**Функции:**
- Просмотр всех бронирований пользователя
- Фильтрация по статусу (предстоящие, завершенные, отмененные)
- Редактирование бронирования (изменение даты/времени)
- Отмена бронирования
- Скачивание чека (PDF)
- Автоматический возврат средств при отмене оплаченного бронирования

**Статусы бронирований:**
- `pending` — ожидает подтверждения
- `confirmed` — подтверждено
- `hold` — временная резервация (ожидает оплаты)
- `cancelled` — отменено
- `completed` — завершено
- `rejected` — отклонено владельцем

### 5. Избранное (Таңдаулылар)

**Функции:**
- Добавление арен в избранное
- Просмотр списка избранных арен
- Быстрый доступ к любимым аренам
- Удаление из избранного

### 6. Рейтинги и отзывы

**Функции:**
- Оставление рейтинга (1-5 звезд)
- Написание текстового отзыва
- Просмотр отзывов других пользователей
- Средний рейтинг арены отображается на карточке

### 7. Профиль пользователя

**Информация:**
- Полное имя
- Email
- Номер телефона
- Роль (USER, OWNER, ADMIN)
- История бронирований
- Настройки уведомлений

**Функции:**
- Редактирование профиля
- Смена пароля
- Выход из системы

### 8. Админ-панель

**Доступ:** Только для пользователей с ролью ADMIN или SUPER_ADMIN

**Функции:**
- Управление пользователями
- Управление аренами
- Просмотр всех бронирований
- Управление платежами
- Просмотр статистики
- Аудит-логи

## 👥 Роли пользователей

### USER (Обычный пользователь)
- Регистрация и авторизация
- Поиск и просмотр арен
- Бронирование арен
- Оплата бронирований
- Управление своими бронированиями
- Добавление в избранное
- Оставление отзывов

### ADMIN (Администратор)
- Все функции USER

- Управление всеми пользователями
- Управление всеми аренами

- Управление платежами

### SUPER_ADMIN (Супер-администратор)
- Все функции ADMIN
- Создание других администраторов
- Системные настройки

## 💳 Система платежей

### Интеграции

**Stripe:**
- Поддержка карт Visa, Mastercard, Amex
- 3D Secure аутентификация
- Webhook для обработки событий
- Автоматические возвраты

**Kaspi Pay:**
- Популярная платежная система в Казахстане
- Интеграция через API
- Поддержка Kaspi Red и других методов

**Cash (Наличные):**
- Бронирование без предоплаты
- Оплата на месте
- Подтверждение владельцем арены

### Процесс оплаты

1. **Создание платежа** → После создания бронирования
2. **HOLD статус** → Бронирование резервируется на 10 минут
3. **Ввод данных** → Пользователь вводит данные карты
4. **Обработка** → Отправка в платежную систему
5. **Успех/Ошибка** → Обработка результата
6. **Webhook** → Получение подтверждения от провайдера
7. **Обновление статуса** → Бронирование → confirmed, Платеж → succeeded
8. **Генерация чека** → PDF с деталями бронирования и оплаты

### Возвраты

- Автоматический возврат при отмене оплаченного бронирования
- Обработка через Stripe/Kaspi Pay API
- Уведомление пользователя о возврате
- Статус: pending → processed → completed

## 🎨 Стеки для дизайна

### Frontend стеки
- **React** + **TypeScript** — основной фреймворк
- **Vite** — сборщик проекта
- **Tailwind CSS** — стилизация и дизайн-система
- **Lucide React** — библиотека иконок
- **Sonner** — toast-уведомления
- **React Router** (hash-based) — маршрутизация

### Backend стеки
- **Node.js** + **Express** — серверная часть
- **Prisma** — ORM для работы с базой данных
- **PostgreSQL** — основная база данных
- **Redis** — кэширование и очереди
- **BullMQ** — обработка фоновых задач
- **Stripe** — интеграция платежей
- **JWT** — аутентификация
- **Winston** — логирование
- **Multer** — загрузка файлов
- **PDFKit** — генерация PDF чеков

### Инфраструктура
- **Docker** — контейнеризация
- **Docker Compose** — оркестрация контейнеров
- **Nginx** — reverse proxy для production
